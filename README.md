## 📋 Описание

Демонстрационное веб-приложение банка с интеллектуальным финансовым ассистентом на основе AI (GigaChat LLM).

**FinAI** - это финансовый ассистент, который:
- 📊 Анализирует ваши расходы и доходы с учетом периодов и категорий
- 💰 Дает персонализированные советы по экономии денег
- 📈 Прогнозирует будущие расходы с учетом сезонных факторов и исторических данных
- 🚀 Рекомендует стратегии инвестирования и приумножения капитала
- 🎓 Обучает финансовой грамотности через интерактивные рекомендации
- 💬 Предоставляет возможность общения с AI-ассистентом (в разработке)

## 🤖 Технологии

- **Frontend:** Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Prisma ORM
- **База данных:** SQLite (для разработки)
- **AI:** GigaChat API (LLM для финансовых рекомендаций с поддержкой русского языка)
- **Аутентификация:** JWT с bcryptjs
- **Визуализация:** Recharts для аналитики
- **Управление состоянием:** Zustand

1. **Клонировать репозиторий и установить зависимости:**
   ```bash

   ```

2. **Создать файл `.env.local`:**

## 📥 Загрузка данных из банковской выписки

### Автоматическая загрузка

После обновления файла `data.txt` выполните:

```bash
npm run update-data
```

Эта команда автоматически:
1. Парсит `data.txt` → создает `scripts/out_parsed.json`
2. Очищает старые транзакции из базы данных
3. Удаляет накопительные счета
4. Загружает новые транзакции в базу данных
5. Обновляет баланс основного счета

### Пошаговая инструкция

#### 1. Парсинг данных
```bash
npm run parse
# или
node scripts/parse_transactions.js data.txt scripts/out_parsed.json
```

#### 2. Загрузка в базу данных
```bash
npm run load
# или
node scripts/load_parsed_data.js
```

## 🔌 API Endpoints

### Аутентификация
- `POST /api/auth/login` - Вход в систему
- `POST /api/auth/register` - Регистрация

### Счета
- `GET /api/accounts` - Получить все счета пользователя
- `POST /api/accounts` - Создать новый счет
- `GET /api/accounts/[id]` - Получить счет по ID
- `PUT /api/accounts/[id]` - Обновить счет
- `DELETE /api/accounts/[id]` - Удалить счет

### Транзакции
- `GET /api/transactions` - Получить транзакции с фильтрами
- `POST /api/transactions` - Создать транзакцию

### Категории
- `GET /api/categories` - Получить категории транзакций

### Аналитика
- `GET /api/analytics` - Получить аналитические данные

### AI-Ассистент
- `POST /api/assistant/analyze` - Анализ расходов за период
- `POST /api/assistant/forecast` - Прогноз будущих расходов
- `POST /api/assistant/savings` - Советы по экономии
- `POST /api/assistant/investment` - Инвестиционные рекомендации

## 🤖 AI-Функции

### Анализ расходов
- Анализирует транзакции за выбранный период
- Определяет основные категории расходов
- Предоставляет персонализированные рекомендации

### Прогноз расходов
- Прогнозирует будущие расходы на основе исторических данных
- Учитывает сезонные факторы и тенденции
- Использует fallback на последний месяц с данными при отсутствии текущих

### Советы по экономии
- Анализирует возможности сокращения расходов
- Предлагает альтернативные варианты трат

### Инвестиционные рекомендации
- Рекомендует распределение средств по инструментам
- Предоставляет стратегии приумножения капитала
- Форматирует рекомендации в читаемом виде

### Что происходит при загрузке

✅ **Очищается:**
- Все транзакции текущего пользователя
- Все накопительные счета (savings)

✅ **Сохраняется:**
- Основной счет (checking) - обновляется балансом
- Пользователь и его настройки
- Категории

✅ **Обновляется:**
- Баланс основного счета из `summary.endBalance`
- Транзакции загружаются заново из `out_parsed.json`
- ФИО в описаниях переводов маскируется (остается только "Фамилия И.")

## 🔐 Безопасность

- В истории операций отображается только "Фамилия И." вместо полного имени
- Данные защищены JWT аутентификацией

- Дата и время операции
- Сумма и валюта
