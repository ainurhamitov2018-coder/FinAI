# FinAI - Интеллектуальный финансовый ассистент

Демонстрационное веб-приложение банка с интеллектуальным финансовым ассистентом на основе Groq AI.

## 🎯 Описание проекта

Проект разработан как бакалаврская выпускная квалификационная работа (ВКР) по направлению **"Инноватика"**.

**FinAI** - это финансовый ассистент, который:
- 📊 Анализирует ваши расходы и доходы
- 💰 Дает советы по экономии денег
- 📈 Прогнозирует будущие расходы
- 🚀 Рекомендует, как приумножить свои деньги
- 🎓 Обучает финансовой грамотности

## 🤖 Технологии

- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Prisma ORM
- **База данных:** SQLite (для разработки)
- **AI:** Groq API (LLM для финансовых рекомендаций)
- **Аутентификация:** JWT

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- npm или yarn

### Установка

1. **Клонировать репозиторий и установить зависимости:**
   ```bash
   npm install
   ```

2. **Создать файл `.env.local`:**
   ```env
   DATABASE_URL="file:./prisma/dev.db"
   JWT_SECRET="your-secret-key-change-in-production"
   GROQ_API_KEY="your-groq-api-key"
   ```

3. **Настроить базу данных:**
   ```bash
   npm run db:generate
   npm run db:push
   ```

4. **Запустить приложение:**
   ```bash
   npm run dev
   ```

5. **Открыть в браузере:**
   ```
   http://localhost:3000
   ```

   **Демо-аккаунт:**
   - Номер карты: `1111222233334444`
   - Пароль: `password123`

## 📥 Загрузка данных из банковской выписки

### Автоматическая загрузка

После обновления файла `data.txt` выполните:

```bash
npm run update-data
```

Эта команда автоматически:
1. Парсит `data.txt` → создает `scripts/out_parsed.json`
2. Очищает старые транзакции из базы данных
3. Удаляет накопительные счета
4. Загружает новые транзакции в базу данных
5. Обновляет баланс основного счета

### Пошаговая инструкция

#### 1. Парсинг данных
```bash
npm run parse
# или
node scripts/parse_transactions.js data.txt scripts/out_parsed.json
```

#### 2. Загрузка в базу данных
```bash
npm run load
# или
node scripts/load_parsed_data.js
```

### Что происходит при загрузке

✅ **Очищается:**
- Все транзакции текущего пользователя
- Все накопительные счета (savings)

✅ **Сохраняется:**
- Основной счет (checking) - обновляется балансом
- Пользователь и его настройки
- Категории

✅ **Обновляется:**
- Баланс основного счета из `summary.endBalance`
- Транзакции загружаются заново из `out_parsed.json`
- ФИО в описаниях переводов маскируется (остается только "Фамилия И.")

## 🔐 Безопасность

- Полные ФИО в описаниях транзакций автоматически маскируются
- В истории операций отображается только "Фамилия И." вместо полного имени
- Данные защищены JWT аутентификацией

## 🛠️ Разработка

### Скрипты

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка для production
- `npm run start` - запуск production версии
- `npm run lint` - проверка кода
- `npm run db:studio` - открыть Prisma Studio
- `npm run parse` - парсинг data.txt
- `npm run load` - загрузка данных в БД
- `npm run update-data` - полное обновление данных

### Парсер банковских выписок

Автоматически парсит банковские выписки в формате таблиц:

```bash
node scripts/parse_transactions.js data.txt output.json
```

**Результат:** JSON с полной информацией о всех операциях, включая:
- Дата и время операции
- Сумма и валюта
- Тип (доход/расход)
- Категория (автоматическая)
- Описание операции (с маскировкой ФИО)
